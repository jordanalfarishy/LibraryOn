Suite penuh dan benchmark dijalankan pada macOS 27.0.1/Xcode 27 di luar sandbox tool karena FSEvents, File Coordination, dan Vision memerlukan layanan macOS yang tidak tersedia dalam sandbox tool. Run suite di dalam sandbox gagal pada layanan tersebut, sedangkan run di luar sandbox lulus. Pengukuran memori dengan `ps` tidak dapat dijalankan: auto-review menolak eskalasi karena batas penggunaan, sehingga tidak ada angka memori yang dilaporkan. Pemeriksaan tanda tangan dan ZIP dilakukan pada paket final setelah edit terakhir; suite penuh terakhir berjalan sebelum tambahan label aksesibilitas, terjemahan label, dan kenaikan versi, sementara build release final berhasil.

Keychain Mac pengembangan memiliki **0 identitas code signing yang valid**. Paket ini bertanda tangan **ad-hoc** dan belum dinotarize. Jangan membagikannya sebagai rilis untuk Mac lain; distribusi eksternal memerlukan B13–B14. Status M4 akan ditutup hanya setelah hasil QA mandiri, pemeriksaan teknis tersisa, dan regresi temuan penghambat dicatat tanpa kegagalan P0 terbuka.
