Pembaruan: 8 Oktober 2026. Status: **berjalan; gate beta belum lulus**. Bukti di bawah berasal dari Mac pengembangan dan corpus sintetis. Hasil benchmark komponen tidak mewakili waktu UI atau pengalaman pada Mac bersih.

Suite akhir dijalankan dengan `swift test` di luar sandbox tool: **78 tes, 76 lulus, 2 dilewati, 0 gagal**. Tes baru memeriksa terjemahan dan label progres menurut locale. Run di dalam sandbox tool gagal pada watcher FSEvents dan OCR Vision akibat layanan macOS yang tidak dapat diakses di sana; keduanya lulus di luar sandbox. Benchmark dijalankan dengan `LIBRARYON_M4_BENCHMARK=1 swift test -c release --filter M4BenchmarkTests` di luar sandbox tool agar FSEvents tersedia. Tes benchmark sengaja dilewati pada `swift test` biasa. Catat ulang angka pada baseline rilis yang ditentukan PRD sebelum menyatakan target p95 terpenuhi.

Lima peserta beta dan akses Developer ID/notarization belum tersedia. Karena itu gate M4 tetap terbuka; tidak ada hasil pengguna atau notarization yang diasumsikan lulus.
