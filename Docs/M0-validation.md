# Validasi Milestone 0 — 6 Oktober 2026

**Keputusan T05: M0 lulus; M1 dimulai.** Build utama PDF Speech **0.2.0 (9)** dibuat dan diverifikasi pada macOS 27.0.1, Apple Silicon, Xcode 27.0, Swift 6.4. Entitlement `com.apple.security.network.client` masuk build utama setelah pengujian QA EPUB offline dan pemblokiran konten jarak jauh lulus. Entitlement memberi aplikasi kemampuan koneksi keluar; pembatasan WebView EPUB tetap diterapkan secara terpisah.

Seluruh **28 tes Swift lulus** ketika dijalankan di luar sandbox tool. Dalam sandbox tool, satu tes Vision OCR gambar gagal dengan `nilError` dari layanan macOS; tes yang sama dan seluruh suite lulus di luar sandbox tool. Perintah: `swift test --disable-sandbox --cache-path /private/tmp/pdf-speech-build-cache --manifest-cache local --scratch-path .build` dengan `CLANG_MODULE_CACHE_PATH` dan `SWIFTPM_MODULECACHE_OVERRIDE` diarahkan ke `/private/tmp`. `bash Scripts/build-app.sh` menghasilkan aplikasi bertanda tangan ad-hoc; `codesign --verify --deep --strict` lulus, entitlement dan versi bundle diperiksa, dan kedua ikon `.icns` terbaca pada resolusi 1024.

**Batas yang dipilih untuk melanjutkan:** PDF/EPUB sumber 100 MB dan PDF 1.000 halaman masih target awal PRD, belum pembatasan yang ditegakkan. Ekstraksi EPUB saat ini dibatasi 10.000 entry dan 500 MB hasil ekstraksi. Pemindaian 1.000 buku telah membuktikan identitas unik dan penelusuran fungsional, belum target latensi p95. Pengukuran performa, PDF besar, izin subfolder yang berubah, dan validasi locator setelah isi file berubah tetap masuk M1–M5. Gate M0 menerima risiko ini karena tugasnya memvalidasi kelayakan stack, bukan menyatakan beta siap dirilis.

M1 dimulai dengan workflow CI macOS untuk build, tes, dan verifikasi tanda tangan/entitlement. Workflow sudah tersimpan tetapi belum memiliki hasil run pada layanan CI; T07 tetap **Sebagian** sampai run nyata lulus. Bug unduhan bahasa yang dilaporkan sebelumnya diperbaiki dengan state persiapan model di tingkat jendela, sehingga status tetap tampil setelah panel terjemahan ditutup; unduhan model yang belum terpasang masih perlu uji perangkat.
